run exits 0 with all analyzers (including the two new precision coupling cases) producing

## Heavy-environment note (read first)

The full harness needs the provisioned toolchain (Node tools vendored via `scripts/setup.sh`
+ `npm install`, Trivy DB pre-fetched, `gitleaks`+`trivy` on PATH, `fastapi`/`uvicorn`),
runs **outside the sandbox** (network for the Trivy DB + the schemathesis HTTP loop), per the
QA README prerequisites. If that environment cannot be stood up in-session, this task's run
is **operator-driven** (the operator runs `run_smoke.py` and reports / commits the
regenerated captures) — the in-sandbox proofs (s5-t0 unit tests, s5-t1 pydeps integration)
remain green regardless. Flag via the autonomy-gate escalation interface if provisioning is
blocked; do not fake captures.
